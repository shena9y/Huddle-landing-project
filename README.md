# Huddle Landing Page — Frontend Mentor Solution

A solution to the **Huddle landing page with a single introductory section** challenge from [Frontend Mentor](https://www.frontendmentor.io). It's a single-section landing page for the fictional "Huddle" community platform, featuring a hero illustration, headline copy, a call-to-action button, and social links.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![Frontend Mentor](https://img.shields.io/badge/Frontend%20Mentor-Challenge-3e54a3)

## ✨ Features

- 🏘️ Single-section landing page: "Build The Community Your Fans Will Love"
- 🖼️ Responsive hero illustration (SVG mockups)
- 🔘 Styled "Register" call-to-action button
- 🌐 Social media icon links (Facebook, Twitter, Instagram) via Font Awesome
- 🎨 Custom background SVGs for desktop and mobile
- 📱 Responsive layout that adapts to small screens

## 🛠️ Tech Stack

- **HTML5** — semantic markup
- **CSS3** — flexbox, media queries
- **Font Awesome** — social icons via CDN
- **Google Fonts** — Roboto

## 📂 Project Structure

```
├── index.html     # Main markup
├── css/
│   └── style.css  # All styles
└── images/        # Logo, illustration, backgrounds, favicon
```

## 🚀 Getting Started

No build step required:

```bash
git clone https://github.com/shena9y/Huddle-landing-project.git
cd Huddle-landing-project
start index.html   # or open it in any browser
```
